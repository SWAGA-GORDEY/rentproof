# Отчёт по безопасности

## Сессия

Cookie `rentproof_session`:

- `HttpOnly: true`
- `SameSite: Lax`
- `Secure` включается в production и когда `RENTPROOF_COOKIE_SECURE=1`
- в базе хранится только SHA-256 хеш токена
- пароль хранится как scrypt, в ответе API пароля нет

Тест `keeps the session cookie inaccessible to scripts` проверяет эти флаги.

## Доступ

Закрытые действия читают пользователя из сессии на сервере. Роль, идентификатор и почту из формы сервер не принимает как доказательство прав.

Владелец объявления проверяется в `updateListing`, `getOwnedListing` и при загрузке фото. Заявку видят только стороны и администратор. Отзыв пишется один раз и только после статуса «завершено». Оценка не приходит отдельным полем, которое клиент мог бы подменить мимо сервера.

Вход блокируется после 8 неудач за 15 минут. Регистрация, объявления, фото, жалобы и контакты имеют отдельные лимиты.

## CSRF и заголовки

Мутации идут через server actions Next.js. `src/proxy.ts` отклоняет POST, PUT, PATCH и DELETE, если `Origin` не совпадает с хостом. Ответы отдают `X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`, `Referrer-Policy` и `Permissions-Policy`.

## Загрузка файлов

Принимаются только JPEG, PNG и WebP по байтам файла, не по расширению. Размер до 2 МБ. Чужие и неопубликованные снимки `GET /media/[id]` не отдаёт.

## Утечка админки

При `cacheComponents` страница и layout рендерятся независимо. Первая проверка прав была только в layout, и анонимный ответ `/admin` уже содержал статистику, названия заявок и события журнала.

Исправление: `requireAdmin()` вызывается в теле каждой админ-страницы до чтения базы. Повторная проверка анонимных `/admin`, `/admin/users` и `/admin/listings` не нашла ни почт, ни названий объявлений.

## Секреты

`.gitignore` исключает `.env`, `.env.*` кроме `.env.example`, файлы SQLite и `data/uploads`. В репозитории нет API-ключей. `.env.example` содержит пустые заглушки.

Предупреждение `MODULE_TYPELESS_PACKAGE_JSON` снято: в `package.json` указано `"type": "module"`. Тестовый прогон его не печатает.

## Что остаётся до коммерческого запуска

- Поднять постоянный хостинг с диском и задать секреты только в панели хостинга.
- Сменить демонстрационные пароли, если они использовались локально.
- Подключить почту и платёжного провайдера отдельным решением, без хранения ключей в Git.
- Добавить строгую Content-Security-Policy с nonce, когда это не сломает скрипты Next.js.
