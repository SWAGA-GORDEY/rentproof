# Отчёт по безопасности

Дата: 21 ноября 2026.

## Закрыто

- Cookie `rentproof_session`: `HttpOnly`, `SameSite=Lax`, `Secure` в production и при `RENTPROOF_COOKIE_SECURE=1`. Значение `0` оставляет cookie без `Secure` только для локального HTTP.
- В базе хранится SHA-256 токена, не сам токен. Пароль — scrypt `32768/8/1`. Читаемого пароля в базе нет.
- После 8 неудачных входов адрес блокируется на 15 минут.
- Регистрация с одного адреса ограничена.
- Изменяющие запросы с чужим заголовком `Origin` отклоняются в `src/proxy.ts` с кодом 403. Сравнение `Origin` с хостом также делает Next.js для server actions.
- Роль и владелец объекта проверяются на сервере. Чужое объявление нельзя изменить. Админ-действия требуют `is_admin`. Заблокированный пользователь теряет сессии и не входит.
- Загрузка принимает только JPEG, PNG и WebP по первым байтам, не по заявленному MIME. Лимит 2 МБ, до 8 снимков у объявления. Имя файла — случайный идентификатор. Путь проверяется на выход из каталога загрузок. Ответ `/media` отдаётся с `X-Content-Type-Options: nosniff`.
- Заголовки ответа: `nosniff`, `Referrer-Policy`, `X-Frame-Options: DENY`, ограниченный `Permissions-Policy`.
- Секреты не коммитятся. `.gitignore` закрывает `.env`, `.env.*` (кроме `.env.example`), файл SQLite и каталог загрузок. В `.env.example` только пустые имена переменных.
- Предупреждение `MODULE_TYPELESS_PACKAGE_JSON` снято: в `package.json` указано `"type": "module"`.

## Ограничения

- Запрос без заголовка `Origin` не отклоняется прокси. Так же ведёт себя защита server actions в Next.js. Браузер на обычной отправке формы заголовок присылает.
- Письма и платежи не подключены, поэтому соответствующие ключи не используются.
- Демонстрационный арендодатель не имеет известного пароля. Его объявления помечены как демонстрационные.
- Юридическую силу фотографий приложение не обещает.

## Проверка

Автоматические тесты подтверждают хеш пароля, хеш сессии, флаги cookie, блокировку входа, запрет чужой роли, запрет чужого редактирования, пересечение дат, отзыв только после завершённой заявки и отказ не-администратору. TypeScript и ESLint завершились без ошибок.
