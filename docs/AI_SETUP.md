# Подключение визуальной оценки

Модуль читает загруженные изображения на сервере и просит модель вернуть JSON. Ключ не попадает в браузер и не хранится в Git.

## Переменные

Задайте их в `.env` локально или в секретах хостинга:

```
OPENAI_API_KEY=sk-...
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_VISION_MODEL=gpt-4o-mini
```

`OPENAI_BASE_URL` можно заменить на совместимый endpoint, который принимает `POST /chat/completions` с `response_format: json_object` и изображениями. Модель должна уметь смотреть картинки.

После изменения переменных перезапустите сервер.

## Если ключа нет

Запрос всё равно сохраняется в `ai_reports`:

- статус `unavailable`;
- `report_json` пустой;
- код ошибки `missing_api_key`.

Страница прямо пишет, что интеграция требует настройки. Подставной текст анализа не создаётся.

## Что отчёт может и чего не может

Отчёт описывает видимые признаки: повреждения, износ, царапины, трещины, качество снимка и области неопределённости. Балл 0–100 — это визуальная оценка по методике в `src/lib/ai.ts`, а не техническая экспертиза. Модель не должна утверждать, что предмет исправен только по фотографии.
