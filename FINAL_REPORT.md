# Итог RentProof

Дата: 21 ноября 2026.

## 1. Что реализовано

Рабочий MVP поверх проверенной авторизации: объявления, каталог, фотографии, заявки на даты, кабинет, отзывы после завершённой аренды, фиксация состояния, жалобы, уведомления в кабинете, админ-панель, тарифы и страница визуальной оценки. Платежи не списываются. Письма не отправляются. Анализ снимков ждёт серверный ключ и не подменяется готовым текстом.

## 2. Маршруты

Публичные: `/`, `/catalog`, `/catalog/[id]`, `/login`, `/register`, `/pricing`, `/about`, `/how-it-works`, `/contacts`, `/faq`.

Кабинет: `/account`, `/account/profile`, `/account/listings`, `/account/bookings`, `/account/bookings/[id]`, `/account/favorites`, `/account/reviews`, `/account/settings`, а также `/account/landlord` и `/account/tenant`.

Объявления: `/listings/create`, `/listings/[id]`, `/listings/[id]/edit`.

Оценка: `/ai-assessment`, `/ai-assessment/[id]`.

Админка: `/admin`, `/admin/users`, `/admin/listings`, `/admin/reports`.

Служебные: `/media/[id]`, `/sitemap.xml`, `/robots.txt`, страница 404 и страница ошибки. Закрытые разделы проверяют сессию и роль на сервере.

## 3. Что реально работает

Регистрация, вход, выход, сессия, профиль, создание и правка своего объявления, черновик и отправка на модерацию, загрузка JPEG/PNG/WebP, каталог и фильтры, избранное, расчёт заявки, запрет пересечения подтверждённых дат, отмена по правилам статусов, отзыв после завершения, жалобы, внутренние уведомления, смена демонстрационного тарифа без оплаты, модерация администратором.

## 4. Что требует ключей

`OPENAI_API_KEY` для настоящего разбора снимков. Инструкция: `docs/AI_SETUP.md`. Почта потребует отдельного SMTP-кода: одних `SMTP_HOST` и `SMTP_FROM` недостаточно, отправка сейчас выключена.

## 5. Что демонстрационное

Цены тарифов, переключение Free / Plus / Pro, суммы аренды и залога, шесть карточек демонстрационного арендодателя. Деньги не списываются. Демонстрационные карточки помечены.

## 6. База

SQLite, файл `data/rentproof.sqlite`, режим WAL. Миграция добавляет новые таблицы и не удаляет старые учётные записи. Подробности и будущий путь к PostgreSQL: `docs/DATABASE.md`.

## 7. Тесты

`npm test`: 16 из 16. Подробности в `TEST_REPORT.md`.

## 8. Оставшиеся ошибки

Постоянный публичный хостинг не подключён. Исходящий туннель Cloudflare с этого компьютера не устанавливается. В `sitemap.xml` до отдельной сборки с боевым адресом остаётся локальный `NEXT_PUBLIC_SITE_URL`.

## 9. Сборка

`npm run build` на Next.js 16.4.6 завершилась успешно, 35 страниц. TypeScript и ESLint без ошибок.

## 10. Безопасность

Cookie сессии HttpOnly, SameSite=Lax и Secure в production. Пароли scrypt, токены сессий хранятся хешем, чужие объекты и админка закрыты на сервере. Секретов в Git нет. Подробности в `SECURITY_REPORT.md`.

## 13. Запуск

```
npm install
copy .env.example .env
npm run dev
```

Администратор: задать `RENTPROOF_ADMIN_EMAIL` и `RENTPROOF_ADMIN_PASSWORD` в окружении и выполнить `npm run admin:bootstrap`. Пароль в чат отправлять не нужно.

## 14. Перед коммерческим запуском
