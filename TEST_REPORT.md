# Отчёт о тестах

Дата: 21 ноября 2026. Каталог: `rentproof-app`. Node.js v26.13.1.

## Автоматические тесты

Команда: `npm test`

Результат: 16 тестов, 6 наборов, 0 падений.

Сохранены исходные проверки:

- scrypt-хеш и отсутствие пароля в профиле
- повторный email
- запрет неизвестной роли в базе
- в сессии только хеш токена, старая сессия не действует
- флаги cookie: HttpOnly, SameSite=Lax, Secure
- верный и неверный пароль, одинаковая ошибка для неизвестного адреса
- блокировка после повторных неудач
- обновление имени, телефона и города без смены роли
- отказ чужой роли
- валидация регистрации, входа и телефона

Добавлены проверки маркетплейса:

- объявление не видно в каталоге до модерации, чужой пользователь не редактирует его, фото сохраняется
- расчёт 3 суток, повтор той же заявки не создаёт вторую, пересечение подтверждённых дат отклоняется
- отзыв только после завершения и только один раз, избранное переключается
- без `OPENAI_API_KEY` отчёт получает статус `unavailable`, текст анализа не подставляется
- SVG отклоняется, лимит тарифа Free срабатывает, не-админ не проходит `assertAdmin`, блокировка запрещает вход
