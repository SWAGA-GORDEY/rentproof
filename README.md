# RentProof

Серверная платформа аренды: регистрация, каталог, объявления, бронирование, фиксация состояния и визуальная оценка фотографий. Платежи не списываются. Без ключа модели AI-отчёт не подменяется готовым текстом.

## Запуск

Нужен Node.js 22 или новее.

```bash
npm install
copy .env.example .env
npm run dev
```

Приложение открывается на http://localhost:3000. База SQLite создаётся в `data/rentproof.sqlite`, фотографии — в `data/uploads`. Эти файлы не коммитятся.

```bash
npm test
npm run lint
npm run build
npm start
```

## Администратор

Публичной регистрации администратора нет. Задайте `RENTPROOF_ADMIN_EMAIL` и `RENTPROOF_ADMIN_PASSWORD` (от 10 символов) в `.env` или в секретах хостинга и выполните:

```bash
npm run admin:bootstrap
```

При старте сервера те же переменные создают администратора, если такого адреса ещё нет. Пароль уже существующего администратора при перезапуске не перезаписывается.

## AI

Ключ хранится только на сервере: `OPENAI_API_KEY`, при необходимости `OPENAI_BASE_URL` и `OPENAI_VISION_MODEL`. Если ключ пуст, отчёт сохраняется со статусом «нужна настройка».

## Данные

Схема применяется при открытии базы и не удаляет существующие учётные записи. Демонстрационные объявления помечены и добавляются только если их ещё нет.
